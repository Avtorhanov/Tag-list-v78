# Tag list

**Tag list** — лёгкое веб-приложение для работы со списками тегов.

### Возможности

- Адрес https://avtorhanov.github.io/Tag-list-v78/

- 📋 Создание и редактирование списков тегов.
- 📷 Добавление тегов из фотографии через OCR.
- ☑️ Отметка выполненных и невыполненных тегов, включая массовое выполнение выбранных тегов.
- 🔗 Передача полного состояния списка по ссылке: страницы, теги, статусы, задания и настройки вида.
- 📝 Добавление заданий к отдельным тегам.
- 📤 Показ и отправка:
  - всего списка;
  - выполненных;
  - невыполненных;
  - заданий.
- 🔤 Изменение размера и типа шрифта.
- 🌙 Переключение темы.
- 📄 Работа с несколькими страницами.
- 💾 Автоматическое сохранение данных в браузере.
- 📱 Адаптация для **iPhone и Android**.
- 📲 Возможность установить приложение на главный экран как PWA.
- ⚡ Кэширование оболочки для быстрого повторного запуска и работы без сети после первого открытия.

### Принцип работы

Приложение работает непосредственно в браузере.  
Основные данные сохраняются локально на устройстве, поэтому список можно использовать без постоянной регистрации или серверной базы данных.

### Назначение

Проект предназначен прежде всего для **быстрой работы с перечнями приборов и оборудования КИПиА** при монтаже, проверке и пусконаладочных работах.

### Надёжность и UX v77

- Выбор тегов и снятие выбора работают отдельно от изменения статуса выполнения.
- Для поддерживаемых браузеров используется тактильный сигнал через Vibration API при изменении статуса; iOS Safari не предоставляет веб-приложениям стандартный API вибрации, поэтому там визуальная обратная связь сохраняется без программной вибрации.
- Зачёркивание статуса анимируется без задержки и не требует перерисовки всего списка.
- При повторном запуске service worker отдаёт закэшированную оболочку сразу и обновляет её в фоне.
